개인정보 처리방침

간호사 시뮬레이터 (베타) · 최종 갱신: 2026-08-15 · 버전 1.2

요약: 본 앱은 학습 데이터를 사용자 기기 안에만 저장하며, 회원가입·로그인이 없습니다. 다만 AI 학습 튜터에 질문을 입력해 전송하는 경우에 한해, 그 질문 내용이 답변 생성을 위해 외부 AI 서비스로 전달됩니다 (아래 5항). 학습 통계·오답 노트 등 저장 데이터 자체는 전송되지 않습니다.

1. 수집·이용하는 정보

다음 항목만 사용자 기기의 브라우저 localStorage 에 저장됩니다. 이 저장 데이터는 외부 서버로 전송되지 않습니다.

  • 학습 통계 (과목별 정답률·콤보 최고점·세트 기록)
  • 오답 노트 (틀린 문제 + Leitner 간격 반복 메타데이터)
  • 북마크 (즐겨찾기한 문제)
  • 에피소드 진행 상태 (이어하기용) + 커리어 기록
  • 사운드·테마 설정
  • 약관 동의 일시
  • 오류 신고 로컬 기록

2. 보유·이용 기간

모든 데이터는 사용자가 직접 삭제하거나 브라우저 데이터를 초기화할 때까지 보유됩니다. 외부로 자동 전송·동기화되지 않습니다 (AI 튜터 질문 전송은 5항 참조 — 사용자가 직접 전송을 실행할 때만 발생).

3. 익명 사용 통계 (선택, 활성화 시에만)

운영자가 서비스 개선을 위해 Plausible Analytics 를 활성화한 경우, 다음과 같은 익명·비식별 통계만 수집됩니다:

  • 페이지 방문 수, 익명 방문자 수 (개인 식별 불가)
  • 주요 기능 사용 이벤트 (예: 일일 챌린지 완료 — 개인 식별 정보 없음)

Plausible 은 쿠키를 사용하지 않으며, IP·기기 지문 등 개인정보를 저장하지 않습니다 (GDPR·PIPA 준수). 현재 베타 버전에서는 기본 비활성화 상태입니다.

4. 광고 (Google AdMob)

Android 앱에는 Google AdMob 보상형 광고가 포함됩니다 (배너·전면 광고는 없음). 사용자가 명시적으로 광고 시청 버튼을 탭한 경우에만 광고가 재생되며, 시청 후 게임 내 보상(부활 / 힌트)을 받습니다.

  • 광고 시청은 완전 선택입니다. 광고를 보지 않아도 모든 학습 기능을 이용할 수 있습니다.
  • 광고 ID(AD_ID)는 Android 13+ 에서 광고 개인화에 사용될 수 있으며, 설정 → Google → 광고에서 끌 수 있습니다.
  • AdMob의 데이터 처리에는 Google의 개인정보 처리방침이 적용됩니다.
  • 한국·EEA·UK 사용자에게는 별도 동의 화면이 표시될 수 있습니다 (Google UMP SDK).
  • 웹(PWA)·데스크톱 버전에는 광고가 없습니다.

5. AI 학습 튜터 (선택 기능)

사용자가 질문을 입력하고 ‘질문하기’를 누른 경우에만 다음이 처리됩니다. 튜터를 사용하지 않으면 아래 전송은 전혀 발생하지 않습니다.

  • 전송되는 것: 사용자가 입력한 질문 문장 + 앱에 내장된 관련 문제·해설 발췌
  • 전송되지 않는 것: 학습 통계, 오답 노트, 북마크, 기기 식별자, 계정 정보 (계정 자체가 없음)
  • 전송 경로: 운영자의 서버 함수를 거쳐 Google Gemini API 로 전달되어 답변이 생성됩니다. 해당 처리에는 Google 의 개인정보 처리방침 이 적용됩니다.
  • 보관: 운영자는 질문 내용을 별도로 저장하지 않으며, 답변 생성 후 즉시 폐기합니다.
  • 주의: 실명·환자 정보 등 개인정보나 실제 환자 식별 정보를 입력하지 마세요. 본 기능은 학습 참고용이며 진단·처방을 제공하지 않습니다.
  • 튜터 기능이 비활성화된 배포본에서는 이 전송이 발생하지 않습니다.

6. 정보 보호 조치

  • 네트워크 통신 최소화 — PWA cache-first / 로컬 실행
  • CSP script-src 'self' — 외부 스크립트 차단 (분석 활성화 시 plausible.io 만 예외)
  • Storage 스키마 검증 — 변조 시 안전 복구

7. 이용자 권리

설정 → 데이터 백업으로 본인 데이터를 JSON 으로 내보낼 수 있습니다. 설정 → 전체 데이터 초기화로 모든 데이터를 영구 삭제할 수 있습니다.

8. 아동 개인정보

본 앱은 만 14세 이상 간호학과 학생·간호사 대상 교육 도구입니다. 만 14세 미만의 개인정보를 의도적으로 수집하지 않습니다.

9. 의료 면책

본 앱의 모든 컨텐츠는 국가시험 학습·교육 목적이며, 실제 임상 진단·치료·의료 행위의 근거로 사용할 수 없습니다. 정식 RN/MD 감수 전 베타 버전이며, 실제 임상 판단은 최신 가이드라인과 면허 의료인을 따라야 합니다.
